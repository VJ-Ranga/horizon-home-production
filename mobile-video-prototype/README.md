# Mobile video section prototype

Standalone, non-production visual experiment for the first four requested sections:

1. Hero
2. Main / Bridge
3. Our Approach to Reporting
4. The Next Horizon of Intelligent Reporting

The separate 30.87-second intro is excluded. The Hero clip starts at the real full-video handoff and covers website frames 1–50; the next three clips cover the real Main, Approach, and Digital ranges. Each clip ends and reveals its matching website frame. Nothing in `src/` imports this folder.

Preview from the repository root with `python3 -m http.server 4173`, then open `/mobile-video-prototype/` at a mobile viewport.
