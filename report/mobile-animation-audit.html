Target Swap Policy

Mobile handoff rule: native readers consume swipes only while content remains inside the reader. At the edge, the next swipe returns to the shared frame timeline and advances to the next settled section. Normal sections do not create a hidden autoplay jump between sections.
  • Hero -> Main 02: one swipe.
  • Main 02 -> Approach: one swipe.
  • Approach -> Digital: one swipe.
  • Digital -> Intro: one smooth swipe, no 6-second logical-frame transition.
  • Capitals Management: native full-section reader, then edge handoff.
  • Strategy: native full-panel reader on compact screens, then edge handoff.
  • Community: native full-stage reader, then edge handoff.
  • All section exits: one predictable handoff after content has completed.
