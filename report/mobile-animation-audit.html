What Is Wrong

M-01: Digital -> Intro is too long. The current navigation calculates frame 161 -> 255 using logical frame distance, approximately 6.03 seconds, even though the timeline contains pinned legs. This creates stop-go-stop movement.
M-02: Startup jitter. Entry timing runs around 10.38fps because ENTRY_SPEED is effectively 2 while nearby comments describe a selected speed above 4.
M-03: Two clocks. Fast compact flicks limit the emitted frame but preserve raw scroll pixels. Ordinary layers and raw-scroll carousel layers can therefore disagree.
M-04: Uneven swipe policy. Virtual holds are not all treated as independent mobile stops, so some sections feel empty and others are crossed too quickly.
M-05: Long card sections. Capitals Management is about 4,442px / 6 swipes; Community is about 4,862px / 7 swipes.

Target Swap Policy

Use one full swipe for normal section handoffs. Use controlled multiple gestures only for content that is genuinely taller than one viewport: Capitals cards, Strategy content, and Community stories. Do not make a virtual hold silently consume six or seven full swipes.
  • Hero -> Main 02: one swipe.
  • Main 02 -> Approach: one swipe.
  • Approach -> Digital: one swipe.
  • Digital -> Intro: one smooth swipe, no 6-second logical-frame transition.
  • Capitals Management: one controlled card step per gesture, with bounded card distance.
  • Strategy: two to four controlled content gestures.
  • Community: one controlled story step per gesture, not a seven-swipe dead lock.
  • All section exits: one predictable handoff after content has completed.

Fix Order

  1. Correct Digital -> Intro duration from actual piecewise scroll distance.
  2. Correct startup speed and remove stop-go-stop in the first 10-20 frames.
  3. Declare a compact policy per section: single-swipe, read-hold, card-step, or content-scroll.
  4. Redesign Capitals and Community budgets around card/story steps.
  5. Reconcile raw scroll and frame-limited visual state during flicks.
  6. Add automated expected-pixels and expected-swipes tests for all 19 sections.
